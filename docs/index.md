features:
  - title: Native performance
    details: Compiles to a native binary. Around 3 ms startup and 20 MB resident memory, with no JVM overhead — suitable for edge and resource-constrained deployments.
  - title: Convention over configuration
    details: Parameter binding is inferred from the signature (path / query / body), so roughly 90% of handlers need no annotations. Routes are grouped by directory convention.
  - title: Security built in
    details: A two-layer Authenticator + Guard architecture with JWT and mock authenticators included (sessions are yours to implement) and annotation-driven authorization.
  - title: Modular components
    details: http, routing, security, redis, cache, database, storage, jobs, ai and logging. Install what you need and compose the rest.
  - title: Structured logging
    details: One Logger API with JSON output, built-in traceId / spanId propagation and automatic redaction, ready for log collection pipelines.
  - title: Compile-time codegen
    details: Controller routes, parameter binding and the Config SPI are all generated by KSP at compile time. No reflection, no runtime scanning.

::: info Version
This documentation covers **Neton 1.0.0-beta1** (Kotlin 2.4.0 / KSP 2.3.10).
